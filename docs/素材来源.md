- 来源：新幕官网规则页 https://main-bakafire.ssl-lolipop.jp/furuyoni/na/rule.html ，`dl/furuyoni_commons_na.zip`（2026-02-16 更新，约 870MB）。
- 用到的部分：
  - 卡图：`furuyoni_na/cards/`，`public/img/cards/`，共 319 张。包括每张卡的最终版，以及中文版印刷后改过的卡的旧版。
  - 塔罗牌：`furuyoni_na/tarots/`，`public/img/tarot/`，31 张加牌背。
  - 女神立绘：`megami/`（18 柱本体），`public/img/megami/<编号>.webp`，等比缩到高 760。首页每次随机显示两位；正在组牌时显示自己选的两位。
  - 讲规则页小图：`public/img/teach/`，来自素材包的 `board_token/board.png`（整张和两处裁切：回合流程、基本动作箭头）、`board_token/master's_distance.png`、`board_token/shrink2.png`、`others/area_*.png`、`others/sakura_token.png`、`cards/cardback_normal.png`、`cards/cardback_special.png`，以及本站卡图和塔罗牌的缩小版，最长边约 160px。集中力卡素材包里没有，截自新幕规则书（https://main-bakafire.ssl-lolipop.jp/furuyoni/na/dl/furuyoni_rulebook.pdf ）PDF 第 13 页（册子 p12）的准备完成图。
  - 樱花结晶图标：`others/sakura_token.png`，`public/img/ui/`，作规则助手头像。
- 处理：等比缩小到宽 480（卡图）或宽 300（塔罗牌），转成 WebP。没有改色，也没有改比例。条款允许整体缩放和裁切；选女神格子用 CSS 裁切显示塔罗牌上半部分。卡图上的“sample”水印是素材包原有的。
- 条款要点（新幕版コモンズ）：
  - 只能用于与本系列相关的内容，非营利。
  - 不能改图，不能再分发。
  - 必须署名“ふるよにコモンズ/BakaFire,TOKIAME”，并附上上面的条款页链接。
  - 站内页脚和卡牌详情都有署名。
- 本站不做卡图墙：卡图只在点开单张卡的详情里显示。

## 卡牌数据

- 骨架：社区组卡器 FuruyoniRandom（https://github.com/bennyhe/FuruyoniRandom ）的新幕 S10-2 数据 `sakura-s10-2-ch.js`。仓库没有声明许可证；本站只取卡名（日文和社区中文译名）、类型、距离、伤害、消耗、纳这些事实数据。
- 核对：每张卡都对照官方素材包里的最终版卡图逐项核对，以卡图为准。影响站内显示的修正有 6 处：雪灯「明敕/暗袭」两面的距离、萨莉娅一张卡的距离、3 个日文卡名的写法；另外把 2 个卡名里的繁体字“複”改成“复”。修正都记在 `tools/cards.json` 的 `fix` 里。
- 效果概括、更新说明、异相说明：本站自己写的，不是官方文字。
- 网站不发布官方卡面文字。`public/data.js` 里没有日文或中文的卡面原文。
- 卡名中文译名来自社区数据。FuruyoniRandom 的说明称其为官方中文版文本，但没有第二个来源可以核对，站内注明“参考社区资料”。
- “已更新”标记：由素材包的卡图文件名后缀判断。后缀如 `_s8_2`，表示该季发布的新版本；`_s9_5` 是 S9-2 的更新（收录在后日谭里）；`rework` 是 S9 神座樱缘起后篇的重做。最终版版本高于 S5 的卡就标为“更新”。中文版是 2020 年众筹、约 S5 时印刷的，所以以 S5 为界。这个界线是推断，没有找到神秘岛关于印刷版本的说明。

## 维护时重新生成数据

需要的原始文件（不放进仓库）：
- FuruyoniRandom 的 `src/config/sakura/carddata/sakura-s10-2-ch.js`
- 素材包解压后的 `furuyoni_na/cards/` 目录

```sh
node tools/make_skeleton.mjs <sakura-s10-2-ch.js> <cards 目录> <skeleton.json>
node tools/build_data.mjs <skeleton.json> tools/cards.json   # 生成 public/data.js
node tools/build_pages.mjs                                   # 生成 public/guide.html
```

骨架里有官方卡面文字，只在本机核对时用，不要提交。
