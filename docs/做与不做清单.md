## 先说三个关键事实

1. **版本已经换代**。2026 年 5 月起，官方换成《桜降る代に決闘を 再演》，运营方是碩星楼（Sekiseiro），新官网 furuyoni.sekiseiro.com；新幕停止更新，也不再有大会支持。当前是**再演 S1-2**（2026-11-06 开始），可用 15 柱女神。禁卡每月第一个周一改定，目前三个赛制都没有禁卡。
2. **正式中文名是“散樱乱武”**（不是“舞”），出版方是神秘岛桌游。再演中文版今年 2 月众筹（1513 人），8 月发货，印的是**繁体中文**；没查到简体实体版，也没有公开的官方中文卡表。
3. **官方二创指南**（furuyoni.sekiseiro.com/re/add-contents/guidelines/）：
   - 非营利二创可以自由做，不用报备。
   - 引用文字必须注明出处，并附官网链接；不能让人误以为是官方出品。
   - 不许扫描或描摹官方图片。图片只能用官方素材包「コモンズ」，不能改图、要署名，而且**禁止“只是罗列素材图片的网页”**。
   - 如果内容复现了游戏规则、能直接玩游戏，要先取得官方许可。只做组牌大概率不算，但建议上线前发邮件告知官方。

## 竞品

## 不做

| 项目 | 理由 |
|---|---|
| 出牌、结算、对战模拟 | 系列规矩不做数字版；而且官方二创指南要求这类内容先取得许可 |
| 卡图墙式的卡表 | 官方素材条款明确禁止“只是罗列素材图片的网页” |
| 自己扫描卡图 | 二创指南禁止 |
| 卡组广场、热门卡组排行 | sdrice 已经有 115 套，用户量差距大；做出来也没人投稿 |
| 收藏管理（分牌、查全不全） | 是真需求（2.8 万播放），但属于收纳，不是组牌 |
| 第二幕（旧幕） | 早已停更 |
| 新幕官中 S10-2 单独一套数据 | 见问题 1 |

## 要用户拍板

1. **版本**：只做再演 S1-2（完全戦 + 起源戦），还是加上古典戦（还要录入 12 柱新幕女神，数据量翻倍，而且新幕已停更）。
2. **卡牌数据**：
   - A：卡名（日文原名 + 社区中文译名）+ 距离、伤害、消耗等数值 + 自己概括的一句话效果，每张都链到官方卡表；
   - B：只有卡名和数值，效果点链接去官方卡表看（日文）；
   - C：在 A 的基础上，点开单张时显示官方素材包里的卡图（要署名；素材包 1.57GB，要下载）。
3. **单机还是房间**：
   - 单机：所有功能在一台手机上；
   - 双人房间：两台手机各自秘密选神、三拾一捨同时公开、组牌计时 5 分钟、对局记录。社区里没找到“同时公开不方便”的抱怨（线下有女神塔罗牌可以盖着翻），所以是推测需求。
4. **规则助手和总入口**：是否照系列惯例接入。

## 其他提醒

- 站名用正式名“散樱乱武”。
- 卡牌中文译名来自社区数据（sdrice 的数据文件自称是官中文本，但没有第二个来源核对），站上注明“译名参考社区，非官方”。
- 总入口要用盒封面。二创指南禁止擅自使用官方图片，素材包里有没有盒封面还没核实；如果没有，需要另外决定。
- 上线前建议用户自己发邮件告知官方（support@sekiseiro.com），我可以起草。

## 用户确认结果（2026-11-07）

- 版本：**做新幕**（不做再演）。依据新幕最终版 S10-2，资料用新幕官网（main-bakafire.ssl-lolipop.jp/furuyoni/na/）的総合ルール、规则书、卡表、更新 PDF。
- 注意：神秘岛的新幕中文实体版（2020 众筹）只收录到第四扩展（约 S5 水平），之后的女神没有中文实体版。
- 卡池（2026-11-07 改）：**只做神秘岛新幕中文版收录的内容**，即基本、达人、第一到第四扩展，共 18 柱女神、13 个异相。用户可以勾选“我有哪些盒”来筛选。
- 卡牌版本：效果按新幕最终版 S10-2 写；中文版印刷（约 S5）之后改过的卡加“已更新”标记，并写明改了什么，依据官方各季的更新公告。
- 卡牌数据：卡名（日文 + 社区中文译名）+ 数值 + 自己概括的效果 + 官方卡表链接；点开单张时显示官方素材包（コモンズ）里的卡图，并署名。不做卡图墙。
- 形态：单机，不做 Room。
- 接入：规则助手和总入口转盘都接。
