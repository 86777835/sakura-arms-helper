# 推荐卡组：来源与收录规则（2026-11-09）

## 收录规则

- **版本**：只收新幕 S10-2 时期（2026-01 至 2026-05）的卡组。例外是官方规则书的入门样例（2020），页面上标明年份，并列出之后改过的牌。再演和 S10 及更早的卡组不收，因为卡牌改过。
- **范围**：两柱都在本站的 18 柱女神和 13 个异相之内。
- **校验**：
  - 每套都用 `public/logic.js` 校验：两柱合法、7+3、没有禁止卡。
  - 卡名按日文原名（日文来源），或本站卡名（中文来源，经译名对照）精确匹配，对不上的不收。
  - `tools/build_decks.mjs` 会拒绝重复卡单。同一份卡单出现在两个来源时只留一套，另一处写进 `also`。
- **不收的**：
  - 卡单不完整的。
  - 有张数靠推断的，例如ワタゆた系列，第 3 张王牌是推断出来的。
  - 没有逐张核实过的。
- **文字**：打法要点都是本站用自己的话概括的，没有照抄原文。卡组名保留原作者起的名字。

## 指标

来源里没有任何卡组级的胜率、使用率或 tier 评级，所以每套都写“强度：无数据”，不自己打分。只列出来源本身有的信息：

| 指标 | 用在哪 | 口径 |
|---|---|---|
| 大会成绩 | 大会卡组 | 这一局的胜负和使用者的总战绩，附原文链接 |
| 出处热度 | B 站攻略文章 | 整篇文章的浏览、点赞、收藏，2026-11-09 读取。一篇文章有好几套卡组，不代表单套强度 |
| 版本提示 | 官方 2020 样例 | 自动列出卡单里 2020 年之后改过的牌 |

查过但没用的：
- 2025 年国内线上赛的女神统计：属于 S10，而且只到女神层面。
- 桜端大会的报名人数：只反映人气，而且数字是从图片读的。
- 各种个人 tier 表：主观评价。

